Act as an expert UX/UI designer and senior front-end developer. Your task is to redesign my existing trading app for beginners based on the provided screenshots and the following detailed design system and specifications.

The primary goals are to:

Create a modern, clean, "tech" aesthetic.

Simplify complex information to make it easily understandable for novice users.

Build user trust in the AI's recommendations.

Improve the overall user flow for analyzing and executing trades.

Please rewrite the entire front-end code to implement the following changes.

Part 1: Global Design System
Apply these styles consistently across the entire application.

Framework: Use React with Tailwind CSS for styling.

Theme: Implement a dark mode theme. The main background color should be a near-black, like #111827 (Tailwind's bg-gray-900).

Color Palette:

Primary Accent: An electric, vibrant blue (#3b82f6 or bg-blue-600) for all primary buttons, active states, and links.

Gain/Positive: A modern, mint green (#10b981 or text-emerald-500).

Loss/Negative: A softer, salmon red (#f43f5e or text-rose-500).

Card Backgrounds: A slightly lighter shade than the main background, like #1f2937 (bg-gray-800).

Typography:

Font: Use the "Inter" font family. Import it from Google Fonts.

Hierarchy:

Headings (e.g., Portfolio Value): Font size 3xl, font-bold.

Sub-headings (e.g., Card Titles): Font size lg, font-semibold.

Body Text: Font size base, font-regular.

Helper Text: Font size sm, text-gray-400.

Layout & Spacing:

Be generous with whitespace. Use a card-based layout.

All cards should have rounded corners (rounded-xl) and consistent internal padding (p-6).

Use consistent margins between elements (my-4, mx-2).

Iconography: Use the Lucide-React icon library for a consistent, minimalist, line-art style.

Part 2: Screen-by-Screen Redesign
Screen 1: Dashboard / Home Screen
Layout: Redesign using a single-column, card-based layout.

Top Card: Portfolio Summary

Display the total portfolio value in a large, bold font (text-4xl, font-bold).

Below it, show "Today's Change" with the dollar amount and percentage, colored appropriately (mint green or salmon red).

Include an interactive line graph of the portfolio's performance. Add filter buttons below it for "1D", "1W", "1M", "3M", "1Y". The active filter should have the primary accent color.

Second Card: "Today's Top AI Signal"

This card must be prominent and visually engaging.

Content: Show the stock ticker (e.g., "AAPL"), the company name ("Apple Inc."), and a concise, AI-generated reason for the signal. For example: "Strong positive momentum detected."

Include a small "AI Confidence: 85%" metric with a visual progress bar.

This entire card should be a single button that navigates to the "AI Trade Suggestion" screen.

Third Card: Watchlist

Keep the watchlist, but simplify each row. Show only the company logo, ticker, current price, and the 24h percentage change.

Bottom Navigation Bar:

Use clean, line-art icons from Lucide-React for Home, Portfolio, Trade, and Profile. The active icon should be highlighted with the primary accent color.

Screen 2: AI Trade Suggestion Screen
This screen is critical for building trust. The focus is on explaining the "why" behind the trade.

Header: Prominently display the company logo, name, and ticker symbol.

Top Section: "AI Analysis in Plain English"

This is a new, crucial section. In a distinct card, display a 2-3 sentence, human-readable summary generated by the AI. Example: "Our system has detected strong, consistent buying momentum ahead of the company's earnings report. Market trends indicate a 75% probability of a short-term price increase."

Second Section: Key Metrics (Visualized)

Do not just list technical data. Convert metrics into simple, visual components:

AI Confidence Score: A large radial progress bar (e.g., 85% full).

Risk Level: A labeled gauge showing "Low," "Moderate," or "High."

Momentum: A labeled gauge showing "Weak," "Neutral," or "Strong."

Potential Gain/Loss: Clearly state the target price and the potential percentage gain.

Chart: Display a clean, simple price chart. You can overlay the AI's projected price path if possible.

Call-to-Action (CTA):

Remove the separate "Buy" and "Sell" buttons.

Add a single, full-width, floating button at the bottom of the screen with the primary accent color. The button text should be "Review Trade".

Screen 3: Trade Execution Flow (New Modal)
Trigger: This flow is initiated by tapping the "Review Trade" button. It should appear as a clean modal sheet sliding up from the bottom.

Content:

Title: "Buy AAPL"

Input: Simplify the investment amount. Use a field for a custom dollar amount, but also provide three quick-action buttons below it: "$50", "$100", "$500".

Summary: As the user enters an amount, dynamically update a summary below. Example: "You will receive approx. 2.5 shares of AAPL."

Final CTA: The primary button at the bottom of the modal should be a "Swipe to Confirm Trade" element. This is a modern interaction that prevents accidental trades. Make it visually clear that it's a swipeable element.
