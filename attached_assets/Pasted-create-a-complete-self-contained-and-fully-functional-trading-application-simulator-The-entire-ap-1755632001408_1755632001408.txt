create a complete, self-contained, and fully functional trading application simulator. The entire application should be built as a single project within Replit, with all necessary files included.

Project Goal
Create a web-based, paper-trading application that simulates a sophisticated trading bot. The app should allow a novice user to select a market (commodities, stocks, or crypto), view a list of suggested trades with key metrics, and "execute" the trades to see a simulated outcome. The app must be visually appealing and user-friendly.

Core Requirements
Technology Stack:

Front-end: Use React for the UI, with Tailwind CSS for all styling to ensure a modern and responsive design.

Back-end: Use a simple Node.js with Express server to provide an API for the front-end to fetch trading opportunities.

Data: Use static mock data on the back-end to simulate a real-time market analysis engine. No real-world market data or external APIs should be used.

User Interface (UI) Components:

Market Selector: A main navigation area with three distinct buttons for "Commodities," "Stocks," and "Crypto." Each button should have an appropriate icon and should change its visual state when selected.

Trading Opportunities Display: A section that dynamically updates to show three different trading opportunities based on the selected market.

Trade Card: Each opportunity should be displayed in a clean, professional-looking card that includes:

Asset Name (e.g., "Gold Futures," "Bitcoin").

Entry Price.

Risk ($).

Potential Gain ($).

Net Profit ($).

"Execute Trade" Button: A prominent button on each trade card to simulate the execution of the trade.

Result Message: A clear and visually distinct message box that appears after a trade is "executed" to provide a success or error message.

Application Logic:

State Management: The front-end should manage its state to show the currently selected market and the corresponding trading opportunities.

API Interaction: The React front-end must make a fetch request to the Node.js back-end API to get the appropriate mock data for the selected market.

Trade Simulation: When the user clicks "Execute Trade," the app should provide a simulated success message. The logic should be simple; there is no need to track a virtual portfolio.

File Structure & Deliverables
Provide all the code in a single response, including the following files:

package.json: For dependencies (React, Express, Tailwind CSS).

tailwind.config.js: The configuration for Tailwind CSS.

src/index.js: The main entry point for the React application.

server/server.js: The Node.js back-end server file.

Ensure all code is well-commented and easy to understand. The final output should be a complete, runnable project that, when started, serves the web application and displays the trading simulator.
