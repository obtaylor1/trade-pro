Build a Forex trading web app that supports:

Paper trading (simulator) first, with real-time quotes.

Modular design to later plug in live trading via regulated broker APIs.

Accurate P/L including spreads, commissions, swaps/financing, and multi-currency accounting.

Tech

Frontend: React + TypeScript, Vite, Zustand (state), React Query (data), Charting (e.g., lightweight-charts).

Backend: Node.js + TypeScript (Express/Fastify), WebSocket for live prices, PostgreSQL (Prisma).

Infra: Dotenv for secrets, modular adapters for data & broker APIs, 12-factor config.

Testing: Vitest/Jest + Playwright (critical flows).

Core Features (MVP)

User Onboarding

Create profile: name, base currency (USD/EUR/etc.), starting balance (min $100 for simulator).

Risk settings: max risk/trade (%), max daily loss (%), leverage cap (e.g., ≤ 30:1 for demo).

Market Data

Real-time quotes (bid/ask, mid), depth optional; major pairs (EURUSD, GBPUSD, USDJPY, XAUUSD, etc.).

Historical OHLC for multiple timeframes (1m, 5m, 1h, 4h, 1d).

Order Entry

Order types: Market, Limit, Stop, Stop-Limit.

Position sizing by lots (micro/mini/standard) and risk-based sizing (e.g., 1% stop distance).

SL/TP in pips/price; trailing stop.

Validation: margin check, minimum notional, risk limits.

Execution Engine (Simulator)

Fill logic: market at best bid/ask; limit/stop at touch with slippage model (configurable).

Costs: spread, commission (per side), overnight swap (long/short), conversion fees.

FIFO/hedge mode toggle (account setting).

Real-time unrealized/realized P&L, equity, free margin, margin level.

Portfolio & Reporting

Dashboards: balance/equity curve, open positions, orders, trade history.

KPIs: win rate, avg R, expectancy, max DD, Sharpe-like (simple), profit factor.

Per-pair analytics and session heatmap (London/NY/Asia).

Risk Controls

Hard daily loss limit → auto disable new orders if breached.

Per-trade risk cap → block order if > configured %.

Leverage & margin warnings; auto-close at margin call threshold (configurable).

Broker/Price Adapters (Interfaces)

Define IDataFeed (subscribe, history) and IBroker (place/cancel/positions/balances).

Provide MockDataFeed + SimBroker for MVP.

Keep folder structure ready for later adapters (e.g., OANDA/FOREX.com/IBKR).

Audit & Logs

Immutable trade log (server-side), every fill/cost update with timestamps.

Export CSV/JSON of trades & equity curve.

Stretch Goals (nice-to-have)

Strategy sandbox: SMA crossover, breakout, mean-reversion with parameter backtests.

Alerts (price, indicator, SL/TP touched).

Multi-leg basket orders; partial closes; netting vs. hedging switch per account.

Multi-tenancy + OAuth.

Data Models (Prisma-style)
model User {
  id           String   @id @default(cuid())
  name         String
  baseCurrency String   // "USD", "EUR", ...
  startBalance Decimal
  riskPerTrade Decimal   // 0.01 = 1%
  dailyLossMax Decimal   // 0.05 = 5%
  leverageMax  Decimal   // e.g., 30
  createdAt    DateTime  @default(now())
}

model AccountSnapshot {
  id        String   @id @default(cuid())
  userId    String   @index
  time      DateTime @default(now())
  balance   Decimal
  equity    Decimal
  margin    Decimal
  freeMargin Decimal
}

model Order {
  id            String   @id @default(cuid())
  userId        String   @index
  symbol        String   // "EURUSD"
  side          String   // "BUY" | "SELL"
  type          String   // "MARKET" | "LIMIT" | "STOP" | "STOP_LIMIT"
  lots          Decimal  // 0.01=microlot
  price         Decimal? // for limit/stop
  stopLoss      Decimal?
  takeProfit    Decimal?
  trailingPips  Int?
  status        String   // "NEW" | "FILLED" | "CANCELED" | "REJECTED" | "PARTIAL"
  createdAt     DateTime @default(now())
}

model Position {
  id           String   @id @default(cuid())
  userId       String   @index
  symbol       String
  side         String   // "LONG" | "SHORT"
  lots         Decimal
  avgPrice     Decimal
  commission   Decimal   // cumulative
  swap         Decimal   // cumulative
  openedAt     DateTime  @default(now())
  closedAt     DateTime?
  realizedPnL  Decimal   @default(0)
}

model Fill {
  id        String   @id @default(cuid())
  orderId   String   @index
  time      DateTime @default(now())
  price     Decimal
  lots      Decimal
  commission Decimal
  spreadCost Decimal
  slippage   Decimal
}

Key Calculations

Pip value: depends on pair & lot size (support USD quote and non-USD quote with conversion).

PnL (unrealized): (currentPrice - avgPrice) * lotsToUnits * direction converted to base currency.

Margin used: notional / leverage.

Swap: nightly funding per symbol, long/short table (configurable).

API (example)

GET /api/quotes?symbol=EURUSD → live bid/ask, spreads.

GET /api/history?symbol=EURUSD&tf=1m&limit=1000

POST /api/orders → place order (validates risk/margin).

POST /api/orders/:id/cancel

GET /api/positions, GET /api/orders, GET /api/trades

GET /api/metrics → KPIs, equity curve.

WebSocket: subscribe(symbol), pushes ticks & order/position updates.

UI/UX

Top bar: equity, balance, free margin, margin level %, daily P/L.

Left: watchlist (major pairs, spread).

Center tabs: Chart (candles, SL/TP overlays), Order Ticket (risk-based sizing, SL/TP), Depth (optional).

Right: Open positions & orders with net/gross P/L (incl. costs).

Bottom: Trade history + logs; Metrics tab with KPIs, equity chart, win/loss distribution.

Risk/Compliance Notes

Display educational disclaimer: simulation only, not investment advice.

Enforce conservative defaults (risk ≤ 1%/trade, leverage cap, daily loss lockout).

Abstract live trading behind IBroker adapter and do not enable without explicit ENV flags.

Acceptance Criteria (MVP)

Users can create a simulated account (min $100), pick base currency.

Live quotes stream & charts render for at least 10 FX symbols.

Orders fill with realistic costs (spread, commission, swap), and P/L matches test cases within tolerance.

Portfolio metrics update in real time; equity curve renders from snapshots.

Risk gates work (order blocked when > risk% or margin insufficient; trading disabled at daily-loss breach).

All fills, cost adjustments, and liquidations are logged immutably and exportable (CSV).

Test Scenarios

Market vs. limit/stop fills with slippage on fast ticks.

Pip value & P/L correctness for USD quote (EURUSD) and non-USD quote (USDJPY, XAUUSD) with conversion.

Margin call auto-close at threshold (e.g., margin level < 50%).

Daily loss lockout triggers and resets at day boundary.

Swap application across rollovers (T+2 rules simplified; triple-swap Wednesday option).
